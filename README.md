# Cinenova
CINENOVA — VISUAL PRODUCT DESIGN PROMPT

Create a complete high-fidelity visual design system and product screen suite for CineNova, an original premium global streaming platform. The experience must feel cinematic, modern, highly usable, accessible, and premium, without copying Netflix, Disney+, Prime Video, or any other brand’s visual identity, assets, wording, logos, or exact layouts.

BRAND DIRECTION
- Name: CineNova.
- Personality: cinematic, confident, warm, intelligent, trustworthy, international, editorial.
- Visual atmosphere: deep near-black cinema surfaces, warm ivory typography, refined charcoal layers, subtle glass only when it improves hierarchy, and a restrained amber-red brand accent.
- Use original fictional movie/series artwork only. Do not use real film posters, actors, or streaming-service logos.
- Build dark, light, and high-contrast themes. Dark is the primary entertainment viewing theme.

DESIGN TOKENS
Create semantic tokens for canvas, surface, elevated surface, overlay, primary/secondary/muted text, subtle/strong borders, brand default/hover/active, success, warning, danger, info, focus ring, spacing, radii, elevations, grid, typography, and motion.
Suggested dark palette: canvas #0B0D12; surface #151821; elevated #1C202B; ivory text #F7F2EA; muted #B8B6B2; restrained accent #E66D4D. Validate every text/control state against WCAG 2.2 AA.

TYPOGRAPHY AND ICONS
Use Inter, Geist, or another licensed modern sans-serif. Define display, headings, body, labels, captions, and numeric/stat styles. Use large readable type and strong contrast for smart TV. Use a consistent 20/24px icon grid such as Lucide. Every icon-only control must have an accessible label.

MOTION
Use 120–220ms restrained micro-interactions, subtle card lift, opacity/scale transitions, skeleton loading, and smooth rail movement. Support prefers-reduced-motion. Never depend on motion alone to convey meaning.

RESPONSIVE BEHAVIOR
- Mobile 320–639: bottom nav, large touch targets, one/two-column grids, compact metadata, full-screen player.
- Tablet 640–1023: hybrid navigation, denser rails, episode side sheet, split layouts.
- Laptop/Desktop 1024+: top navigation, 12-column layout, full hero, expanded search/filter UI.
- TV: 10-foot viewing, remote directional navigation, obvious focus ring, large cards/text, minimal text entry.

CREATE INDIVIDUAL HIGH-FIDELITY SCREENS FOR:
1. Welcome/onboarding and sign in/sign up
2. Profile picker, create profile, profile PIN, child profile
3. Mobile home, tablet home, desktop home, TV home
4. Genre, collection, editorial and trending pages
5. Search default, suggestions, active search, filters, no-results, results
6. Movie detail page, series detail page, season selector, episode list, trailer state
7. Right-restricted, unavailable, and region/plan restriction states
8. Video player normal state, playback controls, captions menu, audio menu, quality menu, next episode, error/retry, Picture-in-Picture
9. Continue Watching, My List, watch history, ratings/reviews
10. Authorized downloads, active download progress, expired download, download unavailable, limit reached, device management
11. Subscription plans, checkout, billing history, payment failure recovery
12. Account profile, security, sessions/devices, language, theme, notifications, privacy data export/delete
13. Help/support, status page, copyright report, content report
14. Admin dashboard, catalogue, rights editor, editorial rail builder, provider health, analytics, moderation, audit logs

CORE COMPONENTS
Design AppShell, desktop navigation, mobile nav, TV nav, ProfileSwitcher, HeroBanner, ContentRail, PosterCard, LandscapeCard, TitleQuickPreview, SearchBar, filter chips, TitleHero, metadata block, genre pills, cast list, episode row, video player, caption/audio/quality menus, ContinueWatchingCard, MyListButton, rating control, download card, device card, billing card, empty/error/loading states, admin metric cards, data tables, rights editor, and confirmation dialogs.

ACCESSIBILITY REQUIREMENTS
Use visible focus styles, skip links, correct semantic hierarchy, keyboard-accessible rails/player/dialogs, 44px touch targets where possible, no color-only meaning, accessible errors, captions support, screen-reader announcements for playback/download state, and high-contrast support.

OUTPUT
Create an organized Figma-ready design specification: token page, component page, responsive behavior notes, user-flow boards, and individual production-reference screen designs. Include annotations for hover, focus, loading, empty, unavailable, error, and success states. Use original fictional content titles and artwork throughout.
