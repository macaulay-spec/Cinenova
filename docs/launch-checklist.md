# CineNova Launch Checklist

## Legal and content

- [ ] Rights reviewed for every title, territory, plan, and availability window.
- [ ] Offline download permission verified per title/asset.
- [ ] Provider contracts and data processing terms approved.
- [ ] Privacy policy, terms, copyright report flow, and support policies reviewed by counsel.

## Security

- [ ] Threat model reviewed and updated.
- [ ] Secret scanning, SAST, dependency scanning, and container scanning enabled.
- [ ] Provider keys stored only in secret manager with rotation runbook.
- [ ] CSP, HSTS, secure cookies, CSRF, rate limits, and WAF/CDN rules verified.
- [ ] Penetration test complete; critical/high findings remediated.

## Reliability

- [ ] Backups and point-in-time restore tested.
- [ ] Runbooks linked from alerts.
- [ ] SLO owners and on-call schedule assigned.
- [ ] Zero-downtime migration strategy tested.
- [ ] Provider outage and rollback drills complete.

## Product and accessibility

- [ ] WCAG 2.2 AA audit complete.
- [ ] Keyboard, screen-reader, caption, focus, and reduced-motion flows verified.
- [ ] Performance budgets measured on representative mobile.
- [ ] Support team trained on rights-denial and billing states.
