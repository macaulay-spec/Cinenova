# CineNova Design System

## Direction

Cinematic premium dark, original to CineNova and not a copy of any existing streaming brand.

## Tokens

| Token | Value | Usage |
| --- | --- | --- |
| `cinenova.void` | `#05070b` | app background |
| `cinenova.surface` | `#0b0d12` | primary surface |
| `cinenova.panel` | `#11141b` | cards/dialogs |
| `cinenova.ivory` | `#f5f0e8` | primary text |
| `cinenova.muted` | `#c9c5bf` | secondary text |
| `cinenova.accent` | `#e46b4a` | primary CTA/focus |
| `cinenova.amber` | `#d49a48` | editorial highlights |

## Accessibility

- WCAG 2.2 AA minimum.
- Every icon-only control has an accessible label.
- Focus states use visible 2px outlines/rings.
- Motion respects `prefers-reduced-motion`.
- Touch targets are at least 44px high where interactive.
